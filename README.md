# Tidebound: Eggfall

Cast. Steal. Hatch. Escape. A Roblox extraction roguelike with a fishing minigame and an egg gacha.

The Rojo project lives in [`TideboundEggfall/`](TideboundEggfall/README.md). Run `rojo serve` from either the repo root or that folder; both project files point at the same `TideboundEggfall/src` code.
