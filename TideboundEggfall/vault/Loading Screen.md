# Loading Screen

`TideboundLoading` in ReplicatedFirst (13 Oct 2026). The camera slowly circles the moonlit Nest plaza while the game loads, so you see the real game. The title, the bar and the DIVE IN button use the HUD's tile look; the bar fills as art and sound really load. DIVE IN (or a few seconds) hands the camera back, then the intro flyover plays ([[Cutscenes]]).

Rojo maps it from `src/first` ([[Rojo Workflow]]).
