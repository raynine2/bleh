# Base Builder

`BaseBuilder.luau`: a drafted base customisation system: 6 themes (Coastal Cottage free, Tropical Paradise, Modern Glass, Mystical Shrine, Underwater Dome, Celestial Palace up to 500,000 Pearls), 8 rooms (Nest Hall, Equipment Vault, Aquarium Hall, Trophy Room, Workshop, Garden, Library, Observatory) and decorations. **Nothing requires it yet**, so it isn't in the game's [[Home Nest]] until it's hooked up.
