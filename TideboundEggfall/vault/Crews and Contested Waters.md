# Crews and Contested Waters

- **Crews:** solo is the default. A crew forms only from accepted invites, up to 4: +5% Pearls per extra member (solo gets x1.15). Crewmates can't snatch each other's eggs.
- **Contested Waters:** opt-in PvP, off by default and set per dive. A rival behind you can hold 1 s to snatch one carried egg; never within 40 studs of a beacon.

Set up with [[Gate Warden Sel]]. Part of the [[Core Loop]].
