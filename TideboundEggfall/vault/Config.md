# Config

`Config.luau` holds every number, read by both server and client so the odds you see are the odds the server rolls. Highlights:
- `Tiers`, `Pity`, `Mutations` → [[Rarity Tiers]], [[Pity]], [[Mutations]]
- `Eggs`, `Capsules`, `Shards` → [[Gacha]]
- `Rods`, `RodTrials`, `Baits`, `Swipe` → [[Rods]], [[Rod Trials]], [[Fishing]], [[Rod Combo]]
- `Heat`, `Extraction`, `Greed` → [[Heat]], [[Extraction and Greed]]
- `Weather`, `Biomes`, `Kelp` → [[Weather and Wind]], [[Biomes]]
- `Npcs` → [[NPCs]]; `Harbor`, `Base` → [[Harbor Ring]], [[Home Nest]]
